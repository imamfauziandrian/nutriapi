About

nutriapi is an open-source project that exposes Indonesian food nutrition data through a simple REST API. Data is collected from two authoritative sources and merged into a single /foods endpoint, ready to be consumed by any application, website, or research project.

Run one Docker command and the API is available at localhost:3000 — no database setup, no complex installation.

REST API

GET /foods All food records
GET /foods/:id Single record by json-server auto-assigned id
GET /foods?code=AP001 Lookup by unique code
GET /foods?name_like=rice Substring (regex) search on name
GET /foods?calories_gte=0&calories_lte=100 Range filter (0–100 kcal)
GET /foods?_page=1&_limit=20 Pagination

All endpoints are read-only (--read-only mode). Static files from ./public/ are served at GET /.

Data Structure

Field Type Description
code string Unique food identifier
name string Food name
calories number Energy (kcal)
protein number Protein (g)
fat number Total fat (g)
carbo number Carbohydrates (g)
fiber number Dietary fiber (g)

Missing values (- in CSV) default to 0.

Data Sources

Source Records Description
TKPI 1,148 Tabel Komposisi Pangan Indonesia — local Indonesian food data
USDA 8,790 USDA National Nutrient Database (via andrafarm.com)
Total 9,938 Merged into the /foods endpoint

Data Pipeline

CSV format: separator ; (semicolon), decimal , (comma), missing values - become 0 for nutrition columns.
